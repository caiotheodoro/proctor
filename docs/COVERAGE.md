# Coverage

What this measurement cannot see, in the vocabulary of the question it refuses to answer.

**Real traces.** Every trace is rendered by `forge` from a seed. A log from a coding agent, a browser agent, or a customer gateway is a different population. The README states that transfer is unmeasured. Nothing in the card converts the synthetic loss into that population.

**Intent that is not a program.** Jailbreaks, persuasion, and "should this have been said" are not classes. `poisoned_description` is a string inequality against a canonical sentence, not a judgment that the sentence is hostile.

**Tools outside the eight.** An unknown tool name is a `wrong_tool` if it appears in a trace, and `schema_only` stays silent on it because there is no schema to fail. The catalog does not grow inside a run.

**Transport.** MCP, CLI, code-mode, and A2A are the same call here. Which transport a small model survives on is a different experiment and is not varied.

**Streaming and partial calls.** A call is a finished triple `(tool, args, result)`. A token that has already been emitted is outside the loss.

**Missing nuance inside a class.** Each dirty cell plants one mutation from the recipe. A trace with two simultaneous classes is produced by tests of the oracle, and it is not a cell in the splits, so the reported loss is the loss of single-mutation tasks plus the clean cell.

**The judge's prose.** If the model explains and then emits JSON, the parser fails and the prediction is empty. The loss counts that. There is no repair loop.
